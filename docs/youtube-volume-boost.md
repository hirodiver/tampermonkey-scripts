# YouTube 音量ブースト について（ファイル: `youtube-volume-boost.user.js`）

> Twitch 版（`twitch-volume-boost.user.js`）と対になっている。片方を直したら、もう片方にも同じ直しを入れるかを提案する（CLAUDE.md「対になっているスクリプト」）。

YouTube の音量を **100% より上（最大 600%）** まで上げる。Chrome 拡張「Volume Master」と同じく
Web Audio で音を増幅する。

プレーヤーの音量バーを、**つまみ1つで 0〜600% を動かせる1本の長いバー**に置き換える。
目盛りは**対数**（音量が 2 倍になるごとに同じ長さ進む）で、よく使う **0〜100% がバーの約 2/3** を占める（v1.2.0〜）。

```
[🔊][0 ── 25 ── 50 ── 100 │ 200 ── 400 ─ 600] 250%
     白（YouTube の音量）    オレンジ（増幅）
```

## 使い方

1. スピーカーアイコンにマウスを乗せると、長いバーが開く（YouTube の音量バーと同じ開き方）。
   左の約 2/3（白、目盛りまで）が YouTube の音量 0〜100%、その右（オレンジ）が 100〜600%。
   クリック・ドラッグで、1つのつまみのまま 0〜600% を行き来できる。100% の近くでは 100% に吸い付く
2. バーの上で**ホイール**、フォーカスして **←→** でも動く（100% 以下は 5%、上は 10% ずつ）。
   Home で 0%、End で 600%。**バーをダブルクリックで 100% に戻る**
3. **動画をクリックしてから ↑ キー**を押すと、YouTube の音量が 100% に達したあとも
   そのまま 10% ずつ上がる。↓ は増幅分から下がり、100% まで戻ると YouTube の音量が下がり始める
4. 100% を超えている間は、バーを閉じても右に「250%」がオレンジで出たままになる。
   ↑↓ で変えたときは画面上部に「音量 250%」が出る
5. **バーの上で右クリック**（または右の数字をクリック）すると、「きれい（リミッターあり）」と
   「大きく（リミッターなし）」が切り替わる（v1.3.0〜。右クリックは v1.4.0〜、横幅が狭いと数字が隠れるため）。
   「大きく」のときは 100% より右の塗りと数字が赤みがかり、数字の後ろに `!` が付く。選んだほうは次も引き継ぐ（キー `tm-yt-volume-boost-limiter`）
   - **きれい**: 音割れしない代わりに、もともと大きい音はそれ以上大きくならない。
     YouTube の動画は音割れ寸前の大きさで作られていることが多く、600% でも思ったほどうるさくならない
   - **大きく**: Volume Master と同じく素直に増幅する。うるさくなるが、大きい音は割れる
6. 増幅は次に開いたときも引き継ぐ（`localStorage`、キー `tm-yt-volume-boost`）。
   0〜100% の部分は YouTube 自身が覚えている音量

## 1本のバーとしての動き

- 0〜100% の部分は **YouTube の音量そのもの**（プレーヤーの `setVolume` で動かす）。
  YouTube の ↑↓ キーやミュートで変えた音量にも、つまみが追いつく。ミュート中はつまみが 0 で「ミュート」と出る
- 100% より右へ動かすと、YouTube の音量を 100% にし（ミュートも解く）、そのうえで増幅する
- YouTube 側の音量が 100% 未満に下がったら増幅は外す
  （ミュートでは外さない。動画の切り替わりで一瞬だけ値が揺れても外さないよう、0.3 秒待って確かめる）
- 実際の音は「YouTube の音量 × 増幅」。YouTube の音量の自動調整（ラウドネス）も残る

## 長さと目盛り

- **目盛りは対数。** 25→50%、50→100%、100→200%、200→400% がどれも同じ長さになる。
  耳は音量の「比」で大きさを感じるので、どこを動かしても同じくらいの変化に聞こえる
- 対数では 0 を表せないため、3% より小さい音量は左端のわずかな区間（バーの 3%）に 0 まで均等に詰める
  （設定 `LOG_FLOOR` / `LOG_FLOOR_POS`）。`LOG_SCALE = false` にすると v1.1.0 と同じ均等割りに戻る
- バー全体の長さは、YouTube の音量バーでつまみが動く長さ（実測。未計測なら 40px、全画面は 60px）の 6 倍
  （通常 240px + つまみ = 252px）。そのうち 0〜100% は約 160px
- ただし小さいプレーヤーでは、右側のボタンにかぶらないよう**プレーヤーの幅の 30% まで**に縮める
  （設定 `MAX_WIDTH_RATIO`）

## 作りの要点

- **100% 以下なら音声に一切触らない。** 100% を超えたときに初めて `AudioContext` を作り、
  動画を `createMediaElementSource` → `GainNode` → スピーカーへつなぐ。
  一度つないだ動画は外せない（ページを開き直すまで Web Audio 経由で鳴る）ため
- **Chrome の自動再生の制限**: ページを一度もクリックしていないと Web Audio は止まっている。
  止まったまま動画をつなぐと**無音になる**ので、そのときはつながずに待ち、
  最初のクリックかキー入力で動き出してからつなぐ。待っている間はバーの数字が薄くなる
  （前回の増幅を引き継いだまま開いたときに起こりうる）
- **音割れ対策**: 「きれい」のとき、100% を超えている間だけリミッター（`DynamicsCompressor`、しきい値 0dB）を通す。
  しきい値を 0dB より下げると Chrome が音を自動で持ち上げ、表示より大きく鳴る（-2dB で約 +12%）ため 0dB にした
- 増幅率はなめらかに追従させる（`setTargetAtTime`、プツッという音を防ぐ）
- YouTube 本来の音量バーは**消さずに見えなくする**（`visibility: hidden` で枠の外へ）。
  開いた幅を `ResizeObserver` で測り、長さの基準と「開く・閉じる」のきっかけに使う
  （YouTube の音量バーが開いていればこちらも開く）。隠すのはこのバーがすぐ隣に付いているときだけなので、
  付け損ねても YouTube の音量バーは残る
- YouTube のプレーヤーAPI（`getVolume` / `setVolume` / `isMuted`）が見つからないときは、
  元の音量バーを残し、右に 100〜600% の延長部分（64px）だけを付ける（v1.0.0 と同じ形）
- 別オリジンの動画（CORS 無し）はつながない（つなぐと Chrome が無音にする）。
  YouTube の通常の再生は `blob:`（MediaSource）なので対象になる
- ショートやホームのプレビューなど、**後から出てくる `<video>` も再生時につないで同じ倍率で増幅**する
  （バーは通常の再生ページのプレーヤーにだけ付く）
- ↑↓ の横取りは、**プレーヤーにフォーカスがあるとき**（動画をクリックしたあと）だけ。
  ショートでは ↑↓ が前後の動画への移動なので触らない。キーは YouTube より先に受け取るため
  `document-start` で登録する
- 置き場所はセレクタを順に試す: `.ytp-volume-area .ytp-volume-panel` の直後 →
  `.ytp-volume-panel` の直後 → 左の操作列にある 0〜100 のスライダー（`role="slider"`）の直後
  （ここまでは、そのスライダーを隠して置き換える） → `.ytp-volume-area` の末尾 →
  `.ytp-mute-button` の直後 → `.ytp-left-controls` の末尾。
  操作バーが作り直されたら `MutationObserver` で付け直す
- **効かないときは**、コンソールで `__tmYtVolumeBoost.dump()` を実行すると、音量・増幅・
  `AudioContext` の状態・YouTube 側の音量・バーの形と長さ・設置先と、動画ごとのつないだかどうかが出る。
  `__tmYtVolumeBoost.set(300)` で直接変えることもできる（0〜600）

## 注意

- Volume Master など、**ほかの音量拡張と同時に使わない**（倍率が重なる。動画を先につながれていると
  こちらは増幅できず、バーの数字が赤くなる）
- 増幅しすぎると、リミッターがあっても音質は落ちる。スピーカーや耳を傷めないよう、上げすぎに注意
