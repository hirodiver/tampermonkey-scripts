# X 16進デコード について（ファイル: `x-hex-decode.user.js`）

X 上と YouTube のライブチャットで、UTF-8 の16進数文字列をドラッグして選択すると、デコードした文字列を選択範囲の下にパネルで出す。
URL ならパネルに「開く」が付く。「コピー」でデコード結果をクリップボードに入れられる。

- 例: `68747470733a2f2f782e636f6d2f...` → `https://x.com/...`
- 区切りなし・空白区切り・`\x` 付き・`%` 付き・`0x` 付きを受け付ける
- 投稿全体を選んだときは、文中の16進数の連続（8文字以上）を拾ってデコードする
- ドラッグの端が16進数の途中で止まっていても、その16進数の端まで広げて読む（先頭や末尾の取りこぼしを吸収する。v1.1.0）
- UTF-8 として不正なバイト列や、制御文字を含む結果は出さない（日付などの数字で誤って出ないように）
- YouTube のライブチャットでも動く（再生ページ横のチャット・ポップアウトしたチャット・アーカイブのチャットのリプレイ。v1.2.0）。
  チャットは再生ページの中の iframe（`/live_chat`）なので、`@noframes` を外して iframe の中で動かし、X の中の iframe（広告など）では動かさない。
  YouTube のチャットは背景が透明な body の上にあるため、パネルの明暗は `<html dark>` とチャット本体（`yt-live-chat-app`）の背景色で決める
- 閉じ方: パネルの外をクリック / Esc / 別の文字列を選択
- 診断: コンソールで `window.__tmHexDecode.dump()`（いまの選択の判定）、`window.__tmHexDecode.decode('6869')`（任意の文字列を試す）

## 検証

```bash
node --check x-hex-decode.user.js
NODE_PATH=$(npm root -g) node test/x-hex-decode.test.js
```

模擬DOM上でマウスのドラッグ選択を行い、デコード結果・区切り付きの形式・端がずれた選択・対象外の選択・閉じ方・診断を確認する（28項目）。
後半では、再生ページの中の iframe にライブチャットを模して置き、iframe の中で読めること・明るいテーマとダークテーマのパネルの色・チャット以外の iframe では動かないことを確認する（6項目、合計34項目）。
X の実DOMは再現していないため、実機確認の代わりにはならない。
