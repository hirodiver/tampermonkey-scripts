# YouTube チャット高さ調整 について（ファイル: `youtube-watch-chat-fit.user.js`）

ウインドウが狭く、ライブチャットが映像の**下**に出る並びのとき、チャット欄が長すぎて
入力欄が画面の下にはみ出す。スクロールすると今度は映像が上に隠れる。
このスクリプトは、その並びのときに次の3つを行い、
**映像・流れるチャット・入力欄（¥・ハートのボタンを含む）** が一画面に入るようにする。

1. ページ上部の YouTube ロゴ・検索・通知の帯を隠す（v1.1.0）
2. チャット上部の見出し（「チャット ∨」「⋮」「×」）とスーパーチャットの帯を、
   「強調ワード」「非表示リスト」のボタンだけが入る細い帯 1 本にする（v1.1.0）。
   どちらのボタンのスクリプトも入っていなければ、帯ごと消す
3. 映像とチャット欄のあいだ（YouTube は 30px ほど空けている）を 4px に詰める（v1.2.0）
4. チャット欄を画面に収まる高さまで縮める

## 使い方

入れるだけ。設定はない。

- チャットが映像の**横**にある広い窓のとき、全画面表示のときは何もしない。
  窓を広げれば、上の帯もチャットの見出しも元に戻る。
- 縦並びの間は、検索・通知・「⋮」「×」・上位チャットの切替が使えない。使うときは窓を広げる。
  隠したくないものは、スクリプト先頭の `HIDE_MASTHEAD` / `COMPACT_CHAT_HEADER` を `false` にする。
- 高さを縮めるのは必要なときだけ。もともと収まっているときは YouTube の高さのまま。
- 窓の大きさを変えたり、シアターモードで映像の大きさが変わったりすると計算し直す。
- 画面がとても低いときは 240px で止める（流れるチャットが1〜2行になるのを防ぐ）。
  このときはページを少しスクロールして使う。
- 「YouTube チャット入力欄切替」とは別のスクリプトで、一緒に使える
  （あちらはチャットの iframe の中、こちらは外枠の高さだけを触る）。

## 作りの要点

- 入力欄は iframe（`live_chat`）の一番下に固定されていて、iframe は外枠
  `ytd-live-chat-frame` の高さに合わせて伸び縮みする。外枠の `height` / `max-height` を
  `!important` で縮め、`min-height` を 0 にする。
- 高さは「ページ最上部（スクロール 0）でチャットの下端が画面下端から 8px 上に来る値」。
  YouTube 自身の高さを毎回測り直し、それより短いときだけ付ける（長くはしない）。
- 「映像の下にあるか」は、チャット上端が映像下端より下かどうかで決める。
  クラス名や `is-two-columns_` 属性には頼らない。
- 上の帯は `html[data-tm-chat-fit]` の CSS で隠し、本文の下げ幅（`--ytd-masthead-height`・
  `ytd-page-manager` の `margin-top`）も 0 にする。
- チャットの iframe は同じ `www.youtube.com` なので中を触れる。iframe の `<html>` に
  `data-tm-chat-compact` を付け、見出しを中身の見えない高さ 40px の帯にし、
  スーパーチャットの帯（`yt-live-chat-ticker-renderer`）を消す。
  「YouTube チャット強調」（v1.1.0〜）と「YouTube チャット非表示」（v1.9.0〜）は
  この目印を見て、ボタンを帯の中（上から 4px）に置く。iframe が読み込み直されたら付け直す。
- あいだは、チャット枠に負の `margin-top` を付けて詰める。外側の余白と打ち消し合って
  思ったほど上がらないときは、測り直してもう一度だけ足す。あいだが 80px を超えるときは
  別の物が挟まっているとみなして詰めない。
- 窓の大きさ・映像の大きさ（`ResizeObserver`）・チャット枠の作り直し（`MutationObserver`）・
  YouTube による枠のスタイル書き直しを見張って付け直す。

## 診断

コンソールで `__tmWatchChatFit.dump()`。見つけた要素のセレクタ、画面の高さ、チャット上端の位置、
YouTube の高さ、付けた高さ、判定（「縮めた」「チャットは映像の横にある」など）を表で出す。

## 検証

```
NODE_PATH=$(npm root -g) node test/youtube-watch-chat-fit.test.js
```

模擬した再生ページ（チャットの iframe に強調・非表示のスクリプトも流す）で、
上の帯が消えて映像が一番上に来る／映像とのあいだが 4px に詰まる（80px 超は詰めない）／見出しが細い帯になりボタンがその中に入る／
スーパーチャットの帯が消える／ボタンのスクリプトが無ければ帯ごと消える／
縮んで入力欄が画面内に入る／映像の大きさの変化に追従する／
スタイルを書き直されても戻る／枠を作り直されても効く／収まるようになったら元に戻る／
横並びに戻すと全部元に戻る／収まっているときは高さを触らない／最小 240px で止まる、を確かめる。
