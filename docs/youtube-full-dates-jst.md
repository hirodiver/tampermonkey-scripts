# YouTube Full Dates (JST) について

Greasy Fork の "YouTube Full Dates (v3)" (script id 564941) を元にした**独立フォーク**。
`@name` / `@namespace` / 更新URL をすべて差し替えているため、本家の更新は反映されない。

Tampermonkey はスクリプトを `@namespace` + `@name` で識別するため、本フォークは本家とは別スクリプトとして登録される。
本家を入れている場合は**本家を削除**すること（両方動くと日付を二重に書き換えて競合する）。
設定値（`GM_setValue`）もスクリプト単位で分かれるため、フォーク側では初期設定からやり直しになる。

## チャンネル名が日付に置き換わる問題・書き換え後に戻らない問題（v3.8.3）

- チャンネル名に「前」と「日」が入っていると（例: 「毎日の前向き日記」）、相対日付と見なされて
  日付に置き換わっていた。動画カードのメタデータ行はチャンネル名と日付欄が同じ形の `span` で並び、
  先に当たったものを日付欄としていたため。数字の直後に単位が来る文字（「3 日前」「2 years ago」）か
  英語の絶対日付の `span` だけを日付欄とするように直した
- YouTube が同じ `span` の文字だけを書き換えると、処理済みの目印（`data-ytfd-done`）が残っているため、
  次の SPA 遷移まで置き換えなかった。目印に置き換え前の文字（`data-ytfd-original`）と置き換えた後の文字
  （`data-ytfd-applied`）を持たせ、今の文字が置き換えた後の文字と違えば目印を外して処理し直す。
  処理待ちの間に書き換わった場合も、古い結果で上書きしない
