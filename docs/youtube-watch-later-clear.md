# YouTube 後で見る一括削除 について（ファイル: `youtube-watch-later-clear.user.js`）

「後で見る」の中身を一気に消す。YouTube には「全部消す」が無い（「視聴済みの動画を削除」だけある）ため、
各動画の「︙」メニュー →「[後で見る]から削除」を、人の代わりに上から順に押していく。
YouTube 本体のメニューを押すだけで、非公式APIは叩かない。

## 使い方

1. 「後で見る」（`https://www.youtube.com/playlist?list=WL`）を開く。右下に赤い **「後で見るを全部削除」** ボタンが出る
   （ほかのページ・ほかの再生リストでは出ない）
2. 押すと確認が出る。OK で開始。**元には戻せない**
3. 実行中はボタンが **「停止（n件削除済み）」** になる。押すとその場で止まる
4. 一覧は100本ずつ読み込まれるので、見えている分を消し終えたら自動で下までスクロールして続きを読ませ、無くなるまで続ける
5. 終わると（止めたときも）「完了：n件削除」と出て、**消した動画の記録の画面が開く**。
   「ファイルに保存」か「コピー」で手元に残す。念のためページを再読み込みして空になったか確かめる

## 消した動画の記録（v1.1.0、v1.2.0 で画面に出す形に直した）

**v1.1.0 の失敗**: 終わったときに自動でダウンロードさせるだけだった。数分かかる削除のあとの
ダウンロードはクリックに結び付かないため、ブラウザに止められることがあり、実際に記録が手元に残らなかった。
検証はダウンロードを止めないヘッドレス Chromium だけで済ませていて、気付けなかった。

**v1.2.0 から**: 終わったら記録の画面（全文の欄＋「ファイルに保存」「コピー」「閉じる」）を必ず開く。
保存とコピーは人のクリックで行うので止められない。自動ダウンロードも試すが、止められても困らない。
v1.1.0 で消した分も、同じブラウザなら localStorage に残っているので、v1.2.0 の「記録を見る」から開ける
（その後に「全部削除」をもう一度始めていなければ）。

消す直前に、その行から次を読み取って残す。ファイル名は `youtube-watch-later-removed_20261108-2103.txt`
（日本時間の開始日時。日本語のファイル名は環境によって捨てられて「download」になるため英数字にしている）。

```
「後で見る」削除記録
開始: 2026/11/08 21:03:12（日本時間）
終了: 2026/11/08 21:05:40　完了
削除 120件 / 失敗 0件

■ 削除した動画

1. 動画のタイトル
   チャンネル: チャンネル名
   URL: https://www.youtube.com/watch?v=XXXXXXXXXXX
   長さ: 12:34
   再生回数・投稿: 12万 回視聴 / 3日前
   削除: 2026/11/08 21:03:13
```

- URL は再生リストの指定（`&list=WL&index=…`）を外した、動画そのものの URL
- 「投稿」は一覧に出ている表記のまま（「3日前」など）。正確な投稿日は一覧に出ていないので取れない。
  「後で見る」に入れた日も YouTube は出していないため残せない
- 消せなかった動画は「■ 消せなかった動画」に理由付きで分けて出る
- 文字コードは UTF-8（BOM 付き）、改行は CRLF。Windows のメモ帳でも化けない
- 記録は1本ごとに `localStorage`（キー `tm-yt-watch-later-clear-log`）へ書き足すので、
  途中でタブを閉じても残る。後で見るのページに **「記録を見る（n件）」** ボタンが出ていれば、押すと記録の画面が開き直る。
  持つのは直近の1回分だけで、次に「全部削除」を始めると上書きされる
- 「コピー」はクリップボードに入れる。使えない環境では欄を選んだ状態にして古い方法でコピーする
- 自動ダウンロードを試したくなければ `AUTO_SAVE_LOG` を `false` にする（記録の画面は出る）

1本あたり1秒前後かかる（間を `INTERVAL_MS` = 350ms 置いている）。数百本なら数分。
実行中はタブを前面に置いたままにする（裏に回すとブラウザが処理を遅らせる）。

## 作りの要点

- 消せなかった行（メニューに削除が無い・押しても消えない）は飛ばして先へ進む。
  5回続けて失敗したら止める（`MAX_CONSECUTIVE_FAILURES`）。理由はコンソールに `console.warn` で出る
- 一覧の行は `ytd-playlist-video-renderer` を先に試し、だめなら `list=WL` 付きの動画リンクから
  「︙」を含む一番近い入れ物へたどる。メニュー項目は文字（「後で見る…から削除」「から削除」「Remove from」）で探す
- 関連動画など、一覧の外の動画には触らない

## 診断

止まる・何も消えないときは、後で見るのページで DevTools のコンソールから
`__tmYtWatchLaterClear.dump()` を実行する。見つけた行・「︙」ボタンの有無・失敗した行が `console.table` で出る。
メニューを手で開いた状態で実行すると、削除項目を見つけられたかも出る。
記録に「チャンネル不明」などが並ぶときも、この表で読み取れているかを確かめられる。
`__tmYtWatchLaterClear.text()` で記録の本文、`__tmYtWatchLaterClear.show()` で記録の画面、
`__tmYtWatchLaterClear.save()` で保存し直しもできる。

## 検証

```
node --check youtube-watch-later-clear.user.js
NODE_PATH=$(npm root -g) node test/youtube-watch-later-clear.test.js
```

模擬の一覧（続きの読み込みあり）で、全部消えること・関連動画が残ること・確認で断ると消えないこと・
途中で止まること・消せない行を飛ばすこと・ほかのページでボタンが出ないこと、
記録のテキストにタイトル・チャンネル・URL・長さ・投稿時期・削除日時が出ること、
再読み込み後も保存し直せることを確かめる（40項目）。
**クリックから1秒より後のダウンロードを握りつぶす**ようにして、実機のブラウザが自動ダウンロードを
止めた場合を真似ている。この条件で、記録の画面が開くこと・「ファイルに保存」と「コピー」で手元に残せることを見る
（v1.1.0 はこの条件で落ちることを確認済み）。
