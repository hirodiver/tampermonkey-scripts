# 貼り付け用の指示文

スキルが呼ばれなかったときの保険として、常に読まれる場所にも短い指示を置く。
下の枠の中をそのまま貼る。

- **Chat / Cowork**：設定の「Claudeへの指示」（個人の設定）の末尾に追記
- **Claude Code**：`~/.claude/CLAUDE.md`（全プロジェクト共通）の末尾に追記

```text
日本語文書のフォント（常に適用）
日本語の Word・PowerPoint・Excel・PDF を作るとき、フォントの指定がなければ次のようにすること。
- 本文は游明朝、見出しは游ゴシック。社内メモや画面で読む簡単な文書、スライド、表計算はすべて游ゴシック。英数字も同じフォントにそろえ、Calibri などと混ぜない。
- フォント名だけでなく、東アジア用フォントの欄（Word は w:eastAsia、PowerPoint は a:ea）にも同じフォントを入れ、言語を ja-JP にする（HTML は lang="ja"）。
- PDF は作業環境にある日本語フォント（Noto Sans CJK JP、IPAex など）を埋め込み、中国語向けのフォント（WenQuanYi など）は使わない。
- jp-document-fonts スキルがあれば、それに従い、仕上げに確認スクリプトを通す。
```
